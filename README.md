# Style Atlas

All 99 [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) film styles with their demo posters, sorted by the kind of video each one suits (13 video types), with picks for three channels: Under the Hood, Curiosity and DAMN/USA.

Live page: https://abhishekbdev.github.io/style-atlas/
